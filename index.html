¿Qué es HTML?

HTML significa HyperText Markup Language, que en español significa Lenguaje de Marcado de Hipertexto. Es el lenguaje que se utiliza para crear y organizar la estructura de una página web. Con HTML se puede colocar y ordenar contenido como textos, títulos, imágenes, enlaces, videos, listas y formularios. La historia de HTML comenzó a finales de la década de 1980, cuando Tim Berners-Lee, un científico que trabajaba en el CERN, propuso un sistema para compartir información entre investigadores mediante documentos conectados por enlaces. En 1991 se publicó la primera versión de HTML, junto con la idea de la World Wide Web, que permitió consultar documentos mediante Internet. Con el paso de los años, HTML fue evolucionando y se fueron agregando nuevas características para crear páginas web más completas. Posteriormente surgieron diferentes versiones y estándares, hasta llegar a HTML5, que incorporó elementos para trabajar de una manera más moderna con contenido multimedia, formularios y diferentes tipos de información. HTML no es un lenguaje de programación, sino un lenguaje de marcado, ya que su función principal es definir la estructura y organización del contenido de una página. Para complementar HTML se utiliza CSS, que se encarga del diseño y la apariencia, y JavaScript, que permite agregar interactividad y funciones. Actualmente, HTML es una de las bases fundamentales del desarrollo web y se utiliza prácticamente en todo tipo de páginas y sitios de Internet.

Formato de texto

El formato de texto en HTML permite modificar la apariencia y el significado de las palabras dentro de un documento. Existen etiquetas que cambian solo el aspecto visual, como <b> para negrita e <i> para cursiva, y etiquetas equivalentes con significado semántico, como <strong> para resaltar importancia y <em> para dar énfasis, que hoy en día son las más recomendadas. También existen otras etiquetas útiles como <u> para subrayar, <mark> para resaltar texto como si fuera marcatextos, <small> para texto más pequeño, <del> para texto tachado y <sub> o <sup> para subíndices y superíndices. Estas etiquetas permiten dar estructura visual y semántica al contenido sin necesidad de usar CSS.

Caracteres especiales

Algunos caracteres tienen un significado especial en HTML, como los símbolos < y >, usados para las etiquetas. Para poder escribirlos como texto normal, sin que el navegador los confunda con una etiqueta, existen códigos especiales llamados entidades HTML. Cada entidad empieza con el símbolo & y termina con punto y coma.

&lt; se escribe como código y se muestra como: <

&gt; se escribe como código y se muestra como: >

&amp; se escribe como código y se muestra como: &

&quot; se escribe como código y se muestra como: "

&ntilde; se escribe como código y se muestra como: ñ

&copy; se escribe como código y se muestra como: ©

&nbsp; sirve para forzar espacios: aquí    hay varios espacios seguidos.

Enlaces

Los enlaces se crean con la etiqueta a y el atributo href, que indica a dónde lleva el enlace. Pueden apuntar a otra página, a un sitio externo, a una sección dentro de la misma página o a una dirección de correo electrónico. El atributo target con el valor _blank hace que el enlace se abra en una pestaña nueva.

Imágenes

Las imágenes se insertan con la etiqueta img, que no lleva etiqueta de cierre. El atributo src indica la ruta del archivo, alt describe la imagen por si no carga o para personas con lectores de pantalla, y width y height controlan su tamaño en pixeles.

Alineación de imágenes

Con la propiedad float de CSS una imagen se puede alinear a la izquierda o a la derecha, haciendo que el texto la rodee. También se puede centrar una imagen usando margin auto en un elemento de bloque.

Tablas

Las tablas se construyen con la etiqueta table, las filas con tr, los encabezados con th y las celdas con td. Los atributos colspan y rowspan permiten que una celda ocupe varias columnas o varias filas.

Formularios

Los formularios permiten que el usuario introduzca información usando etiquetas como input, select y textarea. HTML incluye validación nativa mediante atributos como required, placeholder, min y max, sin necesitar JavaScript.

Datos personales

Mapas

Sin usar JavaScript ni librerías externas, se puede incrustar un mapa real dentro de una página usando un iframe, que carga otra página web dentro de un recuadro de nuestra propia página.

Sonidos

La etiqueta audio permite reproducir sonido directamente en la página. Con el atributo controls, el navegador muestra automáticamente los botones de reproducir, pausar y ajustar el volumen, sin necesitar JavaScript.
