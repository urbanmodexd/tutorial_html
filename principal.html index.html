¿Qué es HTML?

HTML significa HyperText Markup Language (Lenguaje de Marcado de Hipertexto). Es el lenguaje que se usa para crear la estructura y el contenido de las páginas web (títulos, párrafos, imágenes, enlaces, etc.), usando etiquetas como h1, p, a, entre otras. No es un lenguaje de programación, es de marcado: solo describe el contenido, no tiene lógica. Para el diseño se usa CSS y para la interactividad, JavaScript.

Formato de texto

Para darle forma al texto usamos etiquetas como <b> (negrita) y <i> (cursiva). Los títulos van del <h1> (el más grande) al <h6> (el más chico). Para separar párrafos se usa <p>, y para saltar de línea sin dejar espacio en blanco, <br>.
